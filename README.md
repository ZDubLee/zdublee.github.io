## About

**ZDubLee's Airside Companion** is a desktop companion application designed for flight simulation, virtual air traffic control, livestreaming, and content creation.

The application is being developed to work alongside **Airside ATC** and **Microsoft Flight Simulator**, providing useful airport, simulator, ATC, and streaming information through a dedicated companion interface and OBS-compatible browser overlays.

The goal is to give virtual controllers and streamers a clean way to display important information while controlling traffic and interacting with their livestream audience.

---

## Features

### Airport Information
Display useful airport information including:

- Active airport
- Runway information
- ATC frequencies
- Session information
- Controller-related information

### OBS Browser Overlays

Airside Companion provides browser-source overlays designed for use with **OBS Studio**.

These overlays are intended to display useful ATC and streaming information without covering large portions of the simulator or controller interface.

### Live Simulator Data

Supported information can update automatically as the simulator and Airside session change.

### YouTube Integration

Users may optionally connect their Google and YouTube accounts using **Google OAuth** and **YouTube API Services**.

YouTube integration is intended to support livestream features such as:

- YouTube Live Chat
- Channel information
- Supported subscriber/channel statistics
- Super Chats
- Super Stickers
- Channel memberships
- Livestream activity
- OBS stream alerts and overlays

Connecting a Google or YouTube account is optional and is not required to use the application's core ATC and flight simulation features.

## Google & YouTube API Usage

ZDubLee's Airside Companion uses **Google OAuth** and **YouTube API Services** only when a user chooses to connect their YouTube account.

Authorized YouTube information is used to provide user-facing livestream functionality inside Airside Companion and supported OBS overlays.

Airside Companion does not request or store a user's Google or YouTube password.

Users may revoke application access through their Google Account at any time.

For complete information regarding Google and YouTube data usage, please review the Privacy Policy.

## Simulation Use Only

> **ZDubLee's Airside Companion is intended exclusively for flight simulation, virtual air traffic control, livestreaming, entertainment, and content creation.**

The application is **not intended or approved for real-world aviation use**.

Do not use Airside Companion for:

- Real-world aircraft navigation
- Real-world air traffic control
- Aircraft dispatch
- Operational flight planning
- Safety-critical weather decisions
- Emergency aviation operations
